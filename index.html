Album Collage

Live ↗ · Code ↗

Turns a Spotify listener's top tracks into a collage of album art — duplicate albums filtered out, grid size and shape adjustable, exportable as a PNG.

Node.js Express Spotify Web API OAuth Canvas API
How it works

Problem

A collage built straight from someone's top-tracks list gets crowded with the same three or four albums repeated. The interesting part is the variety, so duplicates needed to go before layout, not after.

Approach

The server handles Spotify's OAuth flow and holds tokens in an httpOnly cookie instead of localStorage, so a token isn't reachable from page script if something else on the page ever were compromised. Expired access tokens refresh silently server-side, so a session survives without sending the user back through login.

Result

Once tracks are pulled, albums are deduplicated by ID before the grid is built. From there the user can switch between square and rectangular layouts, resize the grid with a slider, and export the result as a PNG.

First 1000 Words

Code ↗

Reorders the ~1000 most useful words to learn in a new language around a learner's own interests and profession, instead of handing everyone the same generic frequency list.

Python FastAPI React TypeScript Vite
How it works

Problem

A generic "top 1000 words" list spends a learner's time on whatever is statistically common in a text corpus, not on what they'll actually use — and it quietly drops lower-frequency words that would be genuinely useful to, say, an engineer or a parent.

Approach

A short questionnaire across about fifteen topic modules — profession, interests, life context — builds a personal topic profile. Each word's frequency score is then re-ranked as frequency × (1 + boost × topic_weight), so topically relevant words rise above the generic ranking. Grammatical function words — articles, pronouns, prepositions — are tracked separately, since those stay mandatory regardless of topic.

Result

The output is 1000 ranked words with English glosses and Zipf frequency scores, currently for Spanish and French, built on a frequency corpus (wordfreq) that extends to roughly 40 languages. The results view supports search, topic filtering, CSV export, and "I know this" checkboxes that persist between visits.
