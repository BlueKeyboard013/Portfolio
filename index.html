Album Collage

Live ↗ · Code ↗

Turns a Spotify listener's top tracks into a collage of album art — duplicate albums filtered out, grid size and shape adjustable, exportable as a PNG.

Node.js Express Spotify Web API OAuth Canvas API
How it works

Problem

A collage built straight from someone's top-tracks list gets crowded with the same three or four albums repeated. The interesting part is the variety, so duplicates needed to go before layout, not after.

Approach

The server handles Spotify's OAuth flow and holds tokens in an httpOnly cookie instead of localStorage, so a token isn't reachable from page script if something else on the page ever were compromised. Expired access tokens refresh silently server-side, so a session survives without sending the user back through login.

Result

Once tracks are pulled, albums are deduplicated by ID before the grid is built. From there the user can switch between square and rectangular layouts, resize the grid with a slider, and export the result as a PNG.
